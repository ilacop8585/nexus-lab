# NEXUS Lab

Public website and machine-readable discovery surface for NEXUS Lab.

NEXUS Lab is intentionally positioned as a small independent AI systems project. Public metrics must be derived from verified local state; do not add invented customers, revenue, testimonials or activity.

Custom domain: `lab.nexusword.it`

Public files:
- `index.html`
- `data/public-status.json`
- `agents.json`
- `capabilities.json`
- `llms.txt`
- `robots.txt`
- `sitemap.xml`

Internal paths, credentials, prompts, customer content, private IPs and secrets must never be committed.
